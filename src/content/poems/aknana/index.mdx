---
title: "Aknana"
poetId: "odi-gonzales"
---

<br/>
<br/>
<br/>
<br/>

 <br/>
_(Mount Rainier, MD 20712 )_<br/>
 <br/>
Lagha   tuta ch’illmiy ukchupi<br/>
yanqa yanqa yuyupakumi<br/>
hutun  uywa sayayninta<br/>
salquy salquy puriyninta <br/>
Iaqha tuta ch’ illmiy ukhupi<br/>
yanqa yanqa mosqhopakuni<br/>
warku chaka t’ ankayninta <br/>
purun panpa wayllarkunapi<br/>
wañuy wañuy samayninta <br/>
qhaswaqpura sipas<br/>
hayt’anman wantuyunku<br/>
maki maki yuyuta: <br/>
                              _qocha pinchinkurulla_<br/>
                               _k’anchayun lliph_ <br/>
                               _suntur wasiytkita_<br/>
                               _saway sirina_<br/>
hinapi pay<br/>
ñawin unu p’onqopi<br/>
tiya tiyayuspa<br/>
muhuyayta mañakun <br/>
