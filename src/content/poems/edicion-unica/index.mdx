---
title: "Edición única"
poetId: "felix-contreras"
---

<br/>
<br/>
<br/>
<br/>

Este poema que alaba tu belleza<br/>
nunca alcanzará el millón de ejemplares<br/>
ni el júbilo de editores, funcionarios<br/>
ni críticos (tan escasos).<br/>
Pero es que yo lo hice para ti<br/>
y para este corazón que<br/>
cada noche<br/>
para nosotros dos<br/>
hace esta única edición.<br/>

<br/>
